# sr — 美股產業 ETF 動能輪動策略週報

每日自動更新的美股 11 大產業 SPDR ETF 動能輪動週報。

## Live
👉 [https://tayloryam.github.io/sr/](https://tayloryam.github.io/sr/)

## 策略
- 11 個 SPDR sector ETF（XLK / XLV / XLF / XLE / XLI / XLP / XLY / XLU / XLB / XLRE / XLC）
- 每日計算動能評分，排序後持有最強勢、避開弱勢
- 後端引擎 [QuantCore](https://github.com/TaylorYam/QuantCore) 計算

## 自動化
GitHub Action 每日 00:36 自動更新 `index.html`，GitHub Pages 自動發佈。
